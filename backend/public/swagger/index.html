Khám phá API của bạn

Đăng nhập bằng OTP, chọn chức năng và xem phản hồi trực tiếp từ backend.

Mở trang này từ backend tại /swagger/index.html để thử API. Mở file trực tiếp chỉ xem giao diện.

1. Kết nối tài khoản

Token chỉ giữ trong bộ nhớ của trang, mất khi tải lại. Có thể đăng ký ở danh sách API bên dưới. Google OAuth được thử trong ứng dụng Flutter.

Chưa đăng nhập

2. Chọn yêu cầu

Các thao tác thêm/sửa/xóa tác động dữ liệu thật. Dùng tài khoản thử nghiệm. Không nhập vị trí mẫu như vị trí GPS thực tế của trẻ.

3. Kết quả

Chưa gửi yêu cầu

Chọn GET /health để kiểm tra kết nối.
401: cần đăng nhập · 403: thiếu quyền · 404: không có hồ sơ/quyền truy cập · 429: gửi quá nhiều yêu cầu. Trang thử API tùy chỉnh, không phải Swagger UI/OpenAPI.
